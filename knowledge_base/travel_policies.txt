SMART FLIGHT RESERVATION SYSTEM
TRAVEL POLICIES DOCUMENT
Version: 1.0

1. BOOKING POLICY
Passengers must register and log in before booking flights.
Bookings are confirmed only when seats are available.
Each booking is associated with a passenger and a selected flight.
Passengers can view their booking history after logging in.

2. SEAT AVAILABILITY POLICY
A seat can be allocated only when the selected flight has available seats.
Once a booking is confirmed, the available seat count decreases by one.
When an eligible booking is cancelled, the seat is returned to availability.
The system prevents bookings when no seats are available.

3. CANCELLATION POLICY
Passengers can cancel eligible bookings.
A cancelled booking cannot be cancelled again.
After successful cancellation, the booking status changes to cancelled.
The system restores the allocated seat to the flight's available seat count.

4. PAYMENT POLICY
The system supports the following simulated payment modes:
- UPI
- Card
- Net Banking
- Cash

Payments are associated with individual bookings.
The system checks booking ownership before processing payment.
Cancelled bookings cannot be paid for.
Duplicate successful payments are prevented.

5. REFUND POLICY
Refund eligibility depends on airline rules and ticket conditions.
The project does not currently implement automatic refund processing.
Passengers should contact the airline for actual refund-related information.

6. BAGGAGE POLICY
Baggage allowances vary according to airline, route and ticket category.
Passengers should verify cabin and checked baggage limits with their airline.
Restricted and dangerous items must not be carried.
Airport security regulations must always be followed.

7. AIRPORT SECURITY POLICY
Passengers must carry valid identification and required travel documents.
Passengers must comply with airport security screening.
Arrival times should be confirmed with the airline or airport.

8. FLIGHT INFORMATION POLICY
Flight information in this project is fictional sample data.
The system does not provide live airline schedules.
Flight times and availability should not be treated as real travel information.

9. SYSTEM LIMITATIONS
No real payment gateway is connected.
No automatic refund service is connected.
No live airline API is connected.
Airline-specific baggage and cancellation rules are not dynamically retrieved.

END OF DOCUMENT
